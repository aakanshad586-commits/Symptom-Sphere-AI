The project, simply explained

Making machine learning feel understandable.

From raw symptom labels to a transparent screening output, every step is visible and designed to be explained in a classroom.

01

What is disease prediction?

A classification system learns patterns in labelled symptom data. When you select symptoms, the model compares that pattern with what it learned and returns an educational class label.

See the workflow
02

Why preprocessing matters

Labels are cleaned, missing values are handled, and symptoms become consistent binary features before a model sees them.

03

Human judgment stays central

Symptoms can have many causes. This prototype supports learning, not medical decisions or professional consultation.
